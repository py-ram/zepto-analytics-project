Hi there! Here is my project for the Zepto analytics assignment. I've split the code into three main folders to keep things organized and easy to follow:

Data Pipeline (/data_pipeline): This part collects the data from the web and saves it neatly into the database.

Analytics (/analytics): This is where I explored the numbers to spot trends and built models to make predictions.

Support Assistant (/support_assistant): An AI chatbot I created to help answer support questions automatically.

How to Set It Up
To make reviewing my work as easy as possible, you can install everything you need for all three folders with just one quick command:

Bash
